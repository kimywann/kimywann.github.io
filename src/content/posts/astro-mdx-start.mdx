## MDX를 선택한 이유

MDX를 사용하면 일반적인 마크다운 문법을 유지하면서도, 필요한 곳에 Astro 컴포넌트와 JSX 표현식을 사용할 수 있습니다.

> 글의 구조는 마크다운으로 단순하게 유지하고, 표현이 필요한 부분만 컴포넌트로 확장합니다.

### 작성 원칙

- 제목과 요약은 frontmatter에서 관리합니다.
- 본문에서는 **핵심 문장**을 먼저 작성합니다.
- 파일명은 URL이 되므로 `kebab-case`를 사용합니다.
  - 하위 목록도 일반 마크다운 문법으로 작성할 수 있습니다.
  - 인라인 코드는 `const post = await getEntry()`처럼 표현합니다.

## 코드 블록

Astro는 이 코드 펜스를 Prism 토큰으로 변환하고, 글 전용 스타일시트가 색상과 여백을 적용합니다.

```ts
interface IPost {
  title: string;
  isDraft: boolean;
}

const isPublicPost = (post: IPost) => !post.isDraft;
```
